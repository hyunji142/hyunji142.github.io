소개

국민대학교 경영정보학부에서 경영과 IT를 함께 학습하고 있는 나현지입니다. 두 분야가 조직과 사회의 문제를 해결하는 데 어떻게 결합되는지 탐구하고자 경영정보학부에 진학했으며, 이를 학업과 실습을 통해 구체화해 가고 있습니다.

이 포트폴리오는 학습 내용과 직접 수행한 활동을 체계적으로 기록하고 정리하기 위해 HTML로 직접 제작하여 GitHub Pages로 공개했습니다. 최근에는 Kiro와 Notion을 활용하여 프로젝트의 목표, 진행 상황, 의사결정의 근거를 문서화하고, 이를 바탕으로 작업을 이어가는 방식을 실습하고 있습니다.

결과물뿐 아니라 과정과 판단의 근거를 함께 남기는 것을 중요하게 생각하며, 학기마다 활동을 축적해 성장 과정을 보여 드리고자 합니다.

역량

보유 역량

컴퓨터활용능력 보유

컴퓨터활용능력 자격증을 취득했으며, 엑셀로 데이터를 정리하고 함수를 활용해 문서를 작성할 수 있습니다.

노션 보유

프로젝트 진행 기록을 허브 페이지로 관리하며, 작업 내용과 다음 할 일을 체계적으로 정리합니다.

HTML / CSS 보유

개인 홈페이지를 직접 작성하고 GitHub Pages로 배포했습니다.

GitHub 보유

저장소를 관리하고 홈페이지를 배포·수정하는 과정을 경험했습니다.

키워 나갈 역량

자바스크립트 성장 중

사용자 입력에 반응하는 기능(방명록 입력 검증, 버튼 동작 등)을 구현하는 것을 목표로 기초부터 학습하고 있습니다.

Supabase 성장 중

방명록의 데이터 저장과 조회 기능을 직접 구현하며 데이터베이스 연동을 익히고 있습니다.

데이터 분석 성장 중

ADsP(데이터분석 준전문가) 취득을 목표로 데이터 분석의 기초 개념과 통계를 학습하고 있습니다.
